# Contract: 대화창 (003에서 바뀐 부분)

실행 방법, 버튼 상태, 결과 문구, 닫기 막기, smoke test는 [002 gui.md](../../002-portable-album-app/contracts/gui.md)와 같다.

## 창 구성 (위에서 아래로)

```text
┌ A4 사진 앨범 만들기 ─────────────────────────────────────┐
│ 사진 폴더   [____________________________] [찾아보기…]   │
│ 저장할 PDF  [____________________________] [찾아보기…]   │
│ ┌ 사진 순서 ─────────────────────────────────────────┐ │
│ │ 정렬 [수정한 날짜 순 정렬 ▾]  ☐ 역순(내림차순)으로 정렬 │ │
│ │  1  1_집.jpg  2024-05-01 09:30:15 [▲][▼] [맨 위로][맨 아래로] │ │
│ │  2  2_바다.jpg 2024-05-02 08:00:00 [▲][▼] [맨 위로][맨 아래로] │ │
│ │  …                                            (스크롤)│ │
│ └────────────────────────────────────────────────────┘ │
│ ☐ 파일 이름 앞 "숫자_" 빼고 메모 라벨 넣기                    │
│                [ 앨범 만들기 ]  [ PDF 열기 ]                  │
│ ┌ 결과 ──────────────────────────────────────────────┐ │
│ └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

## 사진 순서 목록

- 사진 폴더 칸의 값이 바뀔 때마다 다시 읽는다(찾아보기, 직접 입력, exe에 폴더 끌어다 놓기 모두). 폴더가 아니면 목록을 비운다.
- 각 줄에는 순번(1부터)과 파일 이름이 있다. 오른쪽에 버튼 4개가 이 순서로 있다.
  - `▲`(한 칸 위로), `▼`(한 칸 아래로), 약간 띄우고 `맨 위로`, `맨 아래로`
- 날짜순으로 정렬했으면 파일 이름과 버튼 사이에 그 날짜(`YYYY-MM-DD HH:MM:SS`)를 보인다. 직접 옮겨 "커스텀"이 되어도 마지막으로 정렬한 방식의 날짜를 계속 보인다. 촬영한 날짜 순에서 촬영 정보가 없는 사진은 `⚠ <수정한 날짜>`로 보인다. ⚠가 붙은 줄이 하나라도 있으면 "역순(내림차순)으로 정렬" 오른쪽에 `⚠ 촬영 정보가 없어 수정한 날짜로 대신함`을 보이고, 없으면 숨긴다. 기호는 U+26A0 하나다(Tk는 컬러 이모지를 그리지 못해 U+FE0F를 붙이지 않는다).
- 사진이 없으면 목록 자리에 `사진이 없습니다.`를 보인다(폴더가 고른 상태일 때).
- 목록은 세로로 스크롤되고, 마우스 휠이 동작한다.
- 처음 창 크기는 화면 높이의 75%를 넘지 않는다(150% 이상 배율에서 창이 화면 밖으로 나가지 않게).

## 정렬

| 조작 | 결과 |
|------|------|
| 정렬 콤보박스에서 방식 선택 | 그 방식으로 정렬, 역순 체크박스 활성 |
| "역순(내림차순)으로 정렬" 토글 | 현재 방식의 순서를 뒤집음 / 되돌림 |
| ▲ ▼ 맨 위로 맨 아래로 중 하나 누름 | 항목 이동, 콤보박스 글자 "커스텀", 역순 체크박스 비활성 |
| 다른 폴더로 바꿈 | 새 목록. "커스텀"이었다면 "이름 순 정렬"로 돌아가고 역순 활성 |

콤보박스의 선택지는 `이름 순 정렬`, `만든 날짜 순 정렬`, `수정한 날짜 순 정렬`, `촬영한 날짜 순 정렬` 네 개다. `커스텀`은 표시만 한다.

촬영한 날짜는 `촬영한 날짜 순 정렬`을 처음 고를 때 폴더당 한 번만 읽는다(사진 헤더를 열어야 해서 큰 폴더에서는 몇 초 걸릴 수 있다).

## "숫자_" 체크박스

- 문구: `파일 이름 앞 "숫자_" 빼고 메모 라벨 넣기`, 기본값은 해제다.
- 마우스를 올리면 곧바로(지연 없이) 설명 창(`album_app.strip_number_help()`)이 체크박스 바로 아래에 뜨고, 마우스가 벗어나거나 누르면 닫힌다. 설명에는 예시(`283_벚꽃 축제 모습.jpg → 벚꽃 축제 모습`, `3_엄마_아빠.jpg → 엄마_아빠`, `2026여행.jpg → 2026여행`)와 체크하지 않았을 때의 동작이 들어 있다. README에는 이 규칙을 적지 않는다.

## 아이콘

- exe 파일 아이콘과 실행한 창의 아이콘은 같은 Tk 깃털 아이콘이다(`packaging/app.ico`, tk86t.dll에서 꺼낸 것).

## 언어와 창 제목

- 같은 프로그램이 `앨범 만들기 (한국어).exe`와 `Photo Album Maker (English).exe` 두 이름으로 있다. exe 이름에 `(English)`가 있으면(대소문자 무시) 창 문구와 결과·경고 문구가 영어다. 소스 실행은 `--english`로 같다.
- 창 제목은 exe 이름에서 `.exe`를 뺀 것이다: `앨범 만들기 (한국어)` / `Photo Album Maker (English)`.
- 명령줄(`make_album.py`)과 `/album`은 계속 한국어다.
- "앨범 만들기"를 누를 때의 값을 `build_album(strip_number=…)`으로 넘긴다.

## 앨범 만들기

- 누른 순간의 목록 순서(`order`)와 체크박스 값으로 `build_album`을 호출한다. 그 뒤 목록을 바꿔도 진행 중인 결과에는 영향이 없다.
- 만드는 중에는 기존 버튼(앨범 만들기, 찾아보기 ×2)만 비활성화한다. 목록 조작은 다음 실행에만 반영되므로 막지 않는다.
