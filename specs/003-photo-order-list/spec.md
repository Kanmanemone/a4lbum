# Feature Specification: 앨범 창에서 사진 순서 정하기와 "숫자_" 빼기 선택

**Feature Branch**: `003-photo-order-list`

**Created**: 2026-10-16

**Status**: Draft

**Input**: User description: "앨범 만들기.exe 창에서 사진 폴더를 지정하면 그 폴더의 이미지 파일들이 리스트로 표시된다. 리스트는 "이름 순 정렬"(기본값), "만든 날짜 순 정렬", "수정한 날짜 순 정렬"로 정렬할 수 있고, 옆의 "역순으로 정렬" 체크박스로 각 정렬의 역순을 토글할 수 있다. 리스트 항목마다 "맨 위로", "한 칸 위로(▲)", "한 칸 아래로(▼)", "맨 아래로" 4개의 버튼이 있어 순서를 세세하게 조정할 수 있고, 이 버튼을 한 번이라도 누르면 정렬 모드는 "커스텀"으로 바뀐다. 앨범 PDF는 리스트에 보이는 순서대로 만들어진다. 기존에 파일 이름 앞의 "숫자_"를 메모 라벨 설명에서 항상 제거하던 기능은 별도 체크박스를 두고 체크했을 때만 제거한다."

## Clarifications

### Session 2026-10-16 (변경 요청)

- 정렬 방식에 "촬영한 날짜 순 정렬"을 더한다. 사진에 기록된 촬영 시각(EXIF)을 쓰고, 없으면 수정한 날짜로 대신한다.
- 날짜순으로 정렬하면 목록 각 줄에 그 날짜를 보인다.
- 체크박스 문구를 "역순(내림차순)으로 정렬", 파일 이름 앞 "숫자_" 빼고 메모 라벨 넣기로 바꾼다.
- 줄 버튼은 ▲ ▼ 뒤에 약간 띄우고 "맨 위로" "맨 아래로" 순서로 둔다.
- `앨범 만들기.exe` 파일 아이콘을 실행 창 아이콘(Tk 깃털)과 같게 한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 사진 목록을 보고 정렬 방식 고르기 (Priority: P1)

사용자가 앨범 창에서 사진 폴더를 고르면, 창 안에 그 폴더의 사진 파일이 앨범에 들어갈 순서대로 목록으로 보인다. 처음에는 "이름 순 정렬"이다. 사용자는 정렬 방식을 "만든 날짜 순 정렬"이나 "수정한 날짜 순 정렬"로 바꿀 수 있고, "역순으로 정렬"을 체크하면 같은 방식의 거꾸로 순서가 된다. "앨범 만들기"를 누르면 목록에 보이는 순서대로 PDF가 만들어진다.

**Why this priority**: 목록이 보여야 순서를 확인하고 조정할 수 있다. 이것만으로도 "어떤 순서로 들어가는지" 미리 알 수 있고 날짜순 앨범을 만들 수 있다.

**Independent Test**: 이름·만든 날짜·수정한 날짜가 서로 다른 순서인 사진 3장으로 폴더를 만들고, 정렬 방식과 역순을 바꿔 가며 목록 순서가 맞는지, 만든 PDF의 사진 순서가 목록과 같은지 확인한다.

**Acceptance Scenarios**:

1. **Given** 빈 창, **When** 사진 폴더를 고르면, **Then** 그 폴더의 사진 파일 이름이 목록에 보이고 정렬 방식은 "이름 순 정렬", "역순으로 정렬"은 해제 상태다.
2. **Given** 목록이 보이는 상태, **When** "만든 날짜 순 정렬"을 고르면, **Then** 목록이 파일을 만든 날짜가 이른 것부터 늦은 것 순으로 바뀐다.
3. **Given** 목록이 보이는 상태, **When** "수정한 날짜 순 정렬"을 고르면, **Then** 목록이 파일을 수정한 날짜가 이른 것부터 순으로 바뀐다.
4. **Given** 어떤 정렬 방식이든, **When** "역순으로 정렬"을 체크하면, **Then** 같은 방식의 거꾸로 순서가 되고, 체크를 풀면 원래 순서로 돌아온다.
5. **Given** 목록이 보이는 상태, **When** "앨범 만들기"를 누르면, **Then** PDF의 사진 순서(1페이지 위, 1페이지 아래, 2페이지 위 …)가 목록의 순서와 같다.

### User Story 2 - 사진 하나하나 순서 옮기기 (Priority: P2)

사용자는 목록의 각 줄에 있는 "맨 위로", "한 칸 위로(▲)", "한 칸 아래로(▼)", "맨 아래로" 버튼으로 사진을 원하는 자리로 옮긴다. 버튼을 한 번이라도 누르면 정렬 방식 표시가 "커스텀"으로 바뀌어, 지금 순서가 사용자가 직접 정한 순서임을 알 수 있다.

**Why this priority**: 정렬만으로 안 되는 세세한 순서 조정이 이 기능의 핵심 가치지만, 목록(US1)이 먼저 있어야 한다.

**Independent Test**: 사진 4장 폴더에서 각 버튼을 눌러 목록 순서와 정렬 방식 표시("커스텀")를 확인하고, 앨범을 만들어 PDF 순서가 목록과 같은지 본다.

**Acceptance Scenarios**:

1. **Given** 목록 [A, B, C, D], **When** C의 "한 칸 위로(▲)"를 누르면, **Then** 목록은 [A, C, B, D]이고 정렬 방식은 "커스텀"이다.
2. **Given** 목록 [A, B, C, D], **When** B의 "한 칸 아래로(▼)"를 누르면, **Then** 목록은 [A, C, B, D]다.
3. **Given** 목록 [A, B, C, D], **When** C의 "맨 위로"를 누르면 [C, A, B, D], B의 "맨 아래로"를 누르면 [A, C, D, B]가 된다.
4. **Given** 맨 위 항목, **When** "맨 위로"나 "한 칸 위로"를 누르면, **Then** 순서는 그대로다(맨 아래 항목의 아래 방향 버튼도 같다).
5. **Given** "커스텀" 상태, **When** 정렬 방식에서 "이름 순 정렬" 등을 다시 고르면, **Then** 직접 정한 순서는 버리고 그 방식으로 다시 정렬한다.
6. **Given** "커스텀" 상태, **When** "앨범 만들기"를 누르면, **Then** PDF는 직접 정한 순서대로 만들어진다.

### User Story 3 - "숫자_"를 뺄지 직접 고르기 (Priority: P3)

사진 이름이 `283_벚꽃 축제 모습.jpg`처럼 앞에 "숫자_"가 붙어 있을 때, 사용자는 창의 체크박스로 메모 라벨에서 그 "숫자_"를 뺄지 고른다. 체크했을 때만 "벚꽃 축제 모습"이 되고, 체크하지 않으면 "283_벚꽃 축제 모습"이 그대로 들어간다.

**Why this priority**: 순서를 창에서 정할 수 있게 되면서 파일 이름 앞 번호가 꼭 필요하지 않게 되었고, 번호가 설명의 일부인 사진도 있으므로 선택할 수 있어야 한다. 단, 정렬 기능과 독립적인 작은 변경이다.

**Independent Test**: `1_집.jpg` 한 장으로 체크 여부를 바꿔 두 번 앨범을 만들고, 라벨이 "집"과 "1_집"으로 다른지 확인한다.

**Acceptance Scenarios**:

1. **Given** 체크박스 해제(기본), **When** `283_벚꽃 축제 모습.jpg`로 앨범을 만들면, **Then** 라벨은 "283_벚꽃 축제 모습"이다.
2. **Given** 체크박스 체크, **When** 같은 사진으로 앨범을 만들면, **Then** 라벨은 "벚꽃 축제 모습"이다.
3. **Given** 체크박스 체크, **When** `7_.jpg`로 앨범을 만들면, **Then** 설명이 비어 기존처럼 라벨 없이 넣고 "설명이 비어 있어" 경고를 낸다.

---

### Edge Cases

- 사진 폴더 칸이 비었거나 폴더가 아닌 경로면 목록은 비어 있다.
- 폴더에 사진이 없으면 목록은 비어 있고, "앨범 만들기"는 기존과 같이 "넣을 사진이 없습니다" 오류를 보인다.
- 숨김 파일, `Thumbs.db` 같은 시스템 파일, 사진 형식이 아닌 파일, 카메라 RAW 파일은 목록에 나오지 않는다(앨범에도 들어가지 않는다).
- 확장자는 사진인데 열 수 없는 파일은 목록에 보이지만, 앨범을 만들 때 기존처럼 경고를 내고 건너뛴다.
- 정렬 기준 날짜가 같은 파일끼리는 이름 순서로 놓는다(목록 순서가 매번 같게).
- 목록을 띄운 뒤 폴더에 파일이 추가되거나 지워진 채로 "앨범 만들기"를 누르면: 지워진 파일은 빠지고, 새로 생긴 파일은 목록 뒤에 이름 순으로 붙어 들어간다.
- 다른 폴더를 고르면 목록은 새 폴더로 바뀌고, "커스텀"이었다면 "이름 순 정렬"로 돌아간다(다른 정렬 방식이었다면 그 방식과 역순 설정을 유지한다).
- 사진이 수백 장이어도 목록은 스크롤되며 창이 멈추지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 창은 사진 폴더 경로가 바뀔 때마다 그 폴더의 사진 파일(앨범에 넣을 대상 형식) 목록을 보여야 MUST 한다. 각 줄에는 순번과 파일 이름이 보인다.
- **FR-002**: 정렬 방식 선택은 "이름 순 정렬", "만든 날짜 순 정렬", "수정한 날짜 순 정렬", "촬영한 날짜 순 정렬" 네 가지를 제공하고, 기본값은 "이름 순 정렬"이어야 MUST 한다.
- **FR-003**: "이름 순 정렬"은 기존 앨범 순서 규칙(파일 이름순, 앞 숫자는 숫자 크기순)과 같아야 MUST 한다.
- **FR-004**: "만든 날짜 순 정렬"과 "수정한 날짜 순 정렬"은 각각 파일 시스템의 만든 날짜·수정한 날짜가 이른 것부터 놓고, "촬영한 날짜 순 정렬"은 사진에 기록된 촬영 시각(없으면 수정한 날짜)이 이른 것부터 놓으며, 날짜가 같으면 이름 순으로 놓아야 MUST 한다. 날짜순으로 정렬한 목록은 각 줄에 그 날짜를 보이고, 촬영 시각이 없어 수정한 날짜를 쓴 줄은 그렇다고 표시해야 MUST 한다.
- **FR-005**: 정렬 방식 옆의 "역순(내림차순)으로 정렬" 체크박스는 현재 정렬 방식의 순서를 정확히 거꾸로 뒤집어야 MUST 한다. 기본값은 해제다.
- **FR-006**: 목록의 각 줄에는 "한 칸 위로(▲)", "한 칸 아래로(▼)", (약간 띄우고) "맨 위로", "맨 아래로" 버튼 4개가 이 순서로 있어야 MUST 하며, 누르면 그 항목을 해당 위치로 옮긴다. 더 갈 곳이 없으면 순서는 그대로다.
- **FR-007**: 4개 버튼 중 하나라도 누르면 정렬 방식 표시는 "커스텀"이 되어야 MUST 한다. "커스텀"은 사용자가 정렬 방식 목록에서 직접 고르는 항목이 아니다.
- **FR-008**: "커스텀"에서 정렬 방식을 다시 고르면 직접 정한 순서를 버리고 그 방식으로 정렬해야 MUST 한다. "커스텀"인 동안 "역순으로 정렬"은 누를 수 없다.
- **FR-009**: "앨범 만들기"는 누른 순간의 목록 순서대로 사진을 배치해야 MUST 한다. 목록에 없던 새 사진은 뒤에 이름 순으로 붙이고, 사라진 사진은 뺀다.
- **FR-010**: 창에는 `파일 이름 앞 "숫자_" 빼고 메모 라벨 넣기` 체크박스가 있어야 MUST 하며, 기본값은 해제다. 체크했을 때만 라벨 설명에서 맨 앞 "숫자_"를 뺀다. 해제면 확장자를 뺀 파일 이름 전체가 설명이 된다.
- **FR-011**: 명령줄 실행(`make_album.py`)과 `/album` 스킬의 결과(이름 순, "숫자_" 빼기)는 바뀌지 않아야 MUST 한다.
- **FR-012**: 창의 다른 동작(기본 저장 경로, 만드는 중 상태, 결과 표시, PDF 열기, 닫기 막기, 원본 보존)은 002 기능과 같아야 MUST 한다.

### Key Entities

- **사진 목록 항목**: 폴더의 사진 파일 하나. 파일 이름, 만든 날짜, 수정한 날짜를 가진다. 목록에서의 위치가 앨범에서의 위치다.
- **정렬 상태**: 정렬 방식(이름 / 만든 날짜 / 수정한 날짜 / 커스텀)과 역순 여부.
- **"숫자_" 빼기 설정**: 라벨 설명에서 맨 앞 "숫자_"를 뺄지 여부(창에서만 고른다).

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사진 폴더를 고른 뒤 목록이 보이기까지 사진 300장 폴더에서 2초 이내다.
- **SC-002**: 어떤 정렬 방식·역순·직접 옮기기 조합에서도 PDF의 사진 순서가 "앨범 만들기"를 누를 때의 목록 순서와 100% 같다.
- **SC-003**: 사진 하나를 맨 위에서 맨 아래로 옮기는 데 클릭 1번이면 된다.
- **SC-004**: 체크박스를 해제하고 만든 PDF의 라벨은 확장자를 뺀 파일 이름과 100% 같고, 체크하고 만든 PDF의 라벨은 기존(001) 규칙의 결과와 100% 같다.
- **SC-005**: 기존 명령줄 실행으로 만든 PDF는 이 기능 전과 페이지 수, 사진 순서, 라벨 문구가 같다.

## Assumptions

- "만든 날짜"와 "수정한 날짜"는 Windows 파일 탐색기의 "만든 날짜"·"수정한 날짜"(파일 시스템 날짜)다. "촬영한 날짜"는 사진 속 EXIF 촬영 시각(DateTimeOriginal, 없으면 DateTimeDigitized)이며, 사진을 열어야 하므로 그 정렬을 고를 때만 읽는다.
- 날짜순은 오래된 것이 위(오름차순)이고, 역순은 최신이 위다.
- 직접 정한 순서와 체크박스 상태는 창을 닫으면 저장하지 않는다(다음 실행 시 기본값).
- 목록은 파일 이름만 보여 주며, 미리보기 그림이나 끌어서 옮기기(drag & drop)는 범위 밖이다.
- 목록에서 사진을 빼는(제외하는) 기능은 범위 밖이다. 폴더의 사진은 모두 앨범에 들어간다.
- 명령줄과 `/album` 스킬에는 순서 지정이나 "숫자_" 선택 옵션을 추가하지 않는다.
- 변경 후 `build_portable.ps1`로 `앨범 만들기.exe`와 `app\`을 다시 만들어 커밋한다.
