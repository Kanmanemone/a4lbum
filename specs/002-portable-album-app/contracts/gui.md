# Contract: 대화창 (`앨범만들기.exe` / `scripts/album_app.py`)

## 실행

| 실행 방법 | 동작 |
|-----------|------|
| exe 더블클릭 | 빈 대화창 |
| 사진 폴더를 exe에 끌어다 놓기(`앨범만들기.exe <폴더>`) | 그 폴더가 채워진 대화창. 자동으로 만들지는 않는다(FR-008). 폴더가 아닌 인자는 무시한다. |
| `앨범만들기.exe --smoke-test <사진폴더> <출력PDF> <로그파일>` | 창 없이 앨범을 만들고 로그 파일(UTF-8)에 `report_lines` 또는 `오류: …`를 쓴다. exit 0 = 성공, 1 = 실패. 빌드 검증용이다(research R4). |

개발 환경에서는 `python scripts/album_app.py`로 같은 창을 띄울 수 있다.

## 창 구성 (위에서 아래로)

```text
┌ A4 사진 앨범 만들기 ──────────────────────────────┐
│ 사진 폴더   [______________________________] [찾아보기…] │
│ 저장할 PDF  [______________________________] [찾아보기…] │
│                    [ 앨범 만들기 ]  [ PDF 열기 ]          │
│ ┌ 결과 ────────────────────────────────────────┐ │
│ │ 알림: … / 경고: … / 완료: 사진 N장 → P페이지 … │ │
│ │ PDF: C:\…\여행_album.pdf                         │ │
│ └──────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

- 창 제목은 "A4 사진 앨범 만들기"다. 창 크기는 조절할 수 있고, 결과 영역은 읽기 전용이며 스크롤된다.
- 화면 배율(125%, 150%, 200% 등)을 인식해 글씨가 흐려지지 않는다. 처음 크기(약 720×420)와 최소 크기(약 520×320)도 배율에 맞춰 키운다(research R9).
- 사진 폴더의 "찾아보기…"는 Windows 폴더 선택 대화상자를 연다.
- 저장할 PDF의 "찾아보기…"는 "다른 이름으로 저장" 대화상자를 연다. 확장자는 `.pdf`이고, 기본값은 현재 출력 경로다. 여기서 고르면 `output_custom=True`가 된다.
- 경로 칸에 직접 입력해도 된다. 사진 폴더 칸을 직접 고치면 `output_custom=False`일 때 저장 경로도 따라 바뀐다.

## 버튼 상태

| 상태 | 앨범 만들기 | 찾아보기 ×2 | PDF 열기 |
|------|-------------|-------------|----------|
| 준비, 성공 기록 없음 | 활성 | 활성 | 비활성 |
| 만드는 중 | 비활성("만드는 중…") | 비활성 | 비활성 |
| 준비, 직전 실행 성공 | 활성 | 활성 | 활성 |

## 문구

- 결과 영역에는 001 CLI의 표준 출력과 같은 줄(`make_album.report_lines`)을 쓴다.
- 오류는 `오류: <AlbumError 메시지>`로 쓰고, 그 앞에 그때까지 모인 경고 줄을 쓴다.
- 폴더를 비운 채 누르면 `사진 폴더를 먼저 골라 주세요.`라고 쓴다.
- 만드는 중에 창을 닫으려 하면 안내 상자에 `앨범을 만드는 중입니다. 끝난 뒤 닫아 주세요.`를 띄우고 닫지 않는다.
- "PDF 열기"는 Windows 기본 연결 프로그램으로 연다(`os.startfile`).
