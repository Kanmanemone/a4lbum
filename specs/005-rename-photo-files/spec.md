# Feature Specification: 앨범 창에서 사진 파일 이름 바꾸기

**Feature Branch**: `005-rename-photo-files`

**Created**: 2026-11-25

**Status**: Draft

**Input**: User description: "앱 화면에서 목록에 뜨는 파일들의 이름을 앱 화면에서 직접 바꿀 수 있으면 좋겠어."

## Clarifications

### Session 2026-11-25 (변경 요청)

- 입력 칸은 순번을 가리지 않고 파일 이름 자리만 덮는다. 고치는 동안에도 몇 번째 사진인지 보인다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 목록에서 파일 이름 바로 바꾸기 (Priority: P1)

메모 라벨은 파일 이름에서 나온다. 사용자는 라벨 문구를 고치려고 탐색기를 따로 열지 않고, 앨범 창의 "사진 순서" 목록에서 파일 이름을 두 번 클릭해 그 자리에서 고친다. Enter를 누르면(또는 Tab 등으로 다른 칸으로 옮겨 가면) 폴더의 실제 파일 이름이 바뀌고, 목록도 새 이름을 보인다.

**Why this priority**: 이 기능의 전부다.

**Independent Test**: `1_집.jpg` 한 장 폴더에서 이름을 두 번 클릭해 `1_우리 집`으로 고치고 Enter를 누른 뒤, 폴더에 `1_우리 집.jpg`가 있고 목록이 그 이름을 보이는지, 앨범 라벨이 바뀌는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 목록에 `1_집.jpg`, **When** 그 이름을 두 번 클릭하면, **Then** 순번은 그대로 보이고 이름 자리가 입력 칸이 되며, 확장자를 뺀 `1_집`이 전부 선택된 채 들어 있다.
2. **Given** 입력 칸, **When** `1_우리 집`으로 고치고 Enter를 누르면, **Then** 파일이 `1_우리 집.jpg`로 바뀌고 목록에도 그 이름이 보인다. 확장자는 그대로다.
3. **Given** 입력 칸, **When** Esc를 누르면, **Then** 아무것도 바뀌지 않는다.
4. **Given** "이름 순 정렬"·날짜 정렬, **When** 이름을 바꾸면, **Then** 목록을 그 정렬로 다시 놓는다. **Given** "커스텀", **Then** 사진은 제자리에 있다.
5. **Given** 이름을 바꾼 뒤, **When** "앨범 만들기"를 누르면, **Then** 메모 라벨은 새 이름에서 나온다.

### Edge Cases

- 이름을 비우거나 그대로 두면 아무것도 바꾸지 않는다.
- 앞뒤 공백은 뺀다.
- `\ / : * ? " < > |`가 들어 있으면 바꾸지 않고, 결과 칸에 쓸 수 없는 글자라고 알린다(다른 폴더로 옮겨지는 일이 없게).
- 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 결과 칸에 알린다. 대소문자만 바꾸는 것은 된다.
- 파일이 열려 있거나 지워져서 바꿀 수 없으면 결과 칸에 이유를 알리고 목록을 다시 읽는다.
- 앨범을 만드는 중에는 이름을 바꿀 수 없다(만드는 중인 파일이 사라지지 않게).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 목록의 파일 이름을 두 번 클릭하면 그 줄의 순번 뒤, 이름 자리에 입력 칸이 열리고(순번은 가리지 않는다), 확장자를 뺀 이름이 전부 선택된 채 들어 있어야 MUST 한다.
- **FR-002**: Enter, 입력 칸에서 포커스가 빠질 때, 다른 이름을 두 번 클릭할 때, "앨범 만들기"를 누를 때 폴더의 파일 이름을 `<입력한 이름><원래 확장자>`로 바꾸고, Esc는 취소해야 MUST 한다.
- **FR-003**: 비었거나 같은 이름이면 아무것도 하지 않고, 쓸 수 없는 글자·이미 있는 이름·OS 오류는 파일을 그대로 둔 채 결과 칸에 알려야 MUST 한다. 다른 파일을 덮어쓰거나 다른 폴더로 옮겨서는 MUST NOT 한다.
- **FR-004**: 이름을 바꾼 뒤 정렬 방식이 "커스텀"이 아니면 그 방식으로 다시 정렬하고, "커스텀"이면 순서를 그대로 둬야 MUST 한다. 사진의 날짜(만든·수정한·촬영한)는 그대로다.
- **FR-005**: 앨범을 만드는 중에는 이름 바꾸기가 열리지 않아야 MUST 한다.
- **FR-006**: "사진 순서" 목록 위에 두 번 클릭해 이름을 바꿀 수 있다는 안내가 보여야 MUST 한다.
- **FR-007**: 명령줄, `/album`, 창의 다른 동작은 바뀌지 않아야 MUST 한다.

## Success Criteria *(mandatory)*

- **SC-001**: 이름 하나를 바꾸는 데 탐색기 없이 두 번 클릭 + 입력 + Enter면 된다.
- **SC-002**: 어떤 입력에서도 다른 파일이 덮어써지거나 사진이 다른 폴더로 옮겨지지 않는다.

## Assumptions

- 확장자는 바꾸지 않는다(사진 형식을 실수로 깨뜨리지 않게). 확장자를 바꾸려면 탐색기를 쓴다.
- 되돌리기(Undo)는 범위 밖이다. 다시 두 번 클릭해 고치면 된다.
- 여러 파일 한꺼번에 이름 바꾸기, 번호 매기기는 범위 밖이다.
- 결과 칸에는 실패만 알린다. 성공은 목록의 새 이름으로 보인다.
