# Contract: `make_album.py` CLI

본체 스크립트의 외부 인터페이스. Claude 바로가기([album-command.md](album-command.md))도 이 계약만 사용한다.

## 사용법

```text
python scripts/make_album.py <PHOTO_DIR> [-o OUTPUT_PDF] [--font FONT_TTF]
```

| 인자 | 필수 | 설명 |
|------|------|------|
| `PHOTO_DIR` | 예 | 사진이 들어 있는 폴더. 하위 폴더는 보지 않는다. |
| `-o`, `--output` | 아니오 | 출력 PDF 경로. 기본값: `<PHOTO_DIR의 부모>/<PHOTO_DIR 이름>_album.pdf`. 있으면 덮어쓴다. |
| `--font` | 아니오 | 라벨 기본 글꼴 TTF 경로. 기본값: `C:\Windows\Fonts\malgun.ttf`. |
| `-h`, `--help` | 아니오 | 도움말. |

## 표준 출력 (stdout)

사람이 읽는 한국어 텍스트, UTF-8. 마지막 줄은 항상 결과 요약이다.

```text
경고: 7_.jpg — 설명이 비어 있어 메모 라벨 없이 넣었습니다.
경고: broken.jpg — 사진 파일을 열 수 없어 건너뛰었습니다.
경고: IMG_0002.CR2 — 지원하지 않는 사진 형식이라 건너뛰었습니다. 카메라 RAW 파일은 JPEG로 내보낸 뒤 넣어 주세요.
알림: IMG_0001.heic — HEIC를 JPEG(품질 95)로 변환해 넣었습니다. 원본 파일은 그대로입니다.
알림: 3_지도.gif — GIF를 PNG(무손실)로 변환해 넣었습니다. 원본 파일은 그대로입니다.
완료: 사진 5장 → 3페이지, 경고 3건
PDF: C:\photos\2026_여행_album.pdf
```

- 경고 줄 형식: `경고: <파일 이름> — <내용>` (SC-006: 파일 이름이 항상 포함됨)
- 알림 줄 형식: `알림: <파일 이름> — <내용>` (형식 변환 등 정보성 메시지. `경고 W건`에는 세지 않음)
- 성공 시 마지막 두 줄: `완료: 사진 N장 → P페이지, 경고 W건` / `PDF: <절대 경로>`

## 종료 코드

| 코드 | 의미 |
|------|------|
| 0 | PDF 생성 성공 (경고가 있어도 0) |
| 1 | PDF를 만들지 못함(그때까지의 경고 줄은 출력함): 폴더 없음, 넣을 사진 0장, 글꼴 없음, 출력 파일 쓰기 실패(예: PDF 뷰어에서 열려 있음) |
| 2 | 인자 오류 |

실패 시 stderr에 `오류: <내용>` 한 줄을 출력한다.

## 보장 사항

- 원본 사진 파일과 `PHOTO_DIR` 안의 내용은 바꾸지 않는다(FR-002a).
- 같은 입력이면 같은 레이아웃이 나온다(결정적 정렬·배치).
- JPEG는 원본 바이트 그대로 PDF에 들어간다(SC-007). 그 밖의 형식은 임시 폴더에서 변환해 넣고(사진은 품질 95 JPEG, 그래픽·투명 이미지는 PNG), 실행이 끝나면 변환본을 지운다.
