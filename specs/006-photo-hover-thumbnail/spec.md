# Feature Specification: 사진 목록에 마우스를 올리면 썸네일 보이기

**Feature Branch**: `006-photo-hover-thumbnail`

**Created**: 2026-11-25

**Status**: Draft

**Input**: User description: "항목에 hover 시 썸네일이 떴으면 좋겠어."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 파일 이름 위에서 사진 미리 보기 (Priority: P1)

사용자가 앨범 창의 "사진 순서" 목록에서 파일 이름에 마우스를 올리면, 잠시 뒤 그 사진의 작은 미리보기가 포인터 옆에 뜬다. 파일 이름만으로는 어떤 사진인지 모를 때, 탐색기를 열지 않고 순서를 정하거나 이름을 바꿀 수 있다.

**Why this priority**: 이 기능의 전부다.

**Independent Test**: 사진 몇 장이 든 폴더를 열고 각 파일 이름에 마우스를 올려, 맞는 사진이 바른 방향으로 뜨고 마우스를 치우면 사라지는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 목록에 사진이 보이는 상태, **When** 파일 이름 위에 마우스를 올리고 잠시 두면, **Then** 그 사진의 미리보기가 포인터 근처에 뜬다.
2. **Given** 미리보기가 뜬 상태, **When** 마우스가 이름 밖으로 나가거나, 누르거나, 목록을 스크롤하면, **Then** 미리보기가 사라진다.
3. **Given** 마우스를 여러 이름 위로 빠르게 지나가면, **Then** 지나친 이름의 미리보기는 뜨지 않고 멈춘 이름의 것만 뜬다.
4. **Given** 휴대폰에서 세로로 찍어 방향 정보가 든 사진, **When** 미리보기가 뜨면, **Then** 앨범에 들어가는 것과 같은 방향으로 보인다.
5. **Given** 열 수 없는 파일(깨진 사진), **When** 마우스를 올리면, **Then** 그림 대신 "미리보기를 볼 수 없습니다"가 뜬다.

### Edge Cases

- 미리보기는 창 밖으로 잘리지 않게 화면 안에 놓인다.
- 이름을 바꾸는 입력 칸이 열린 줄에서는 미리보기가 뜨지 않는다.
- 같은 사진에 다시 마우스를 올리면 처음보다 빨리 뜬다(한 번 만든 미리보기를 다시 쓴다). 폴더를 바꾸거나 이름을 바꾸면 그 사진의 것은 새로 만든다.
- 큰 사진(수십 MB, HEIC)이어도 창이 멈춘 것처럼 보이지 않는다.
- 원본 사진 파일은 바뀌지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 목록의 파일 이름 위에 마우스가 약 0.4초 머무르면 그 사진의 미리보기를 보여야 MUST 한다.
- **FR-002**: 미리보기는 사진의 가로세로 비율을 지키며 긴 변이 화면 기준 약 240픽셀 이하이고, 앨범과 같은 방향(사진의 방향 정보 반영)이어야 MUST 한다.
- **FR-003**: 마우스가 이름 밖으로 나가거나, 누르거나, 목록을 스크롤하면 미리보기를 닫아야 MUST 한다. 머무르기 전에 나가면 띄우지 않는다.
- **FR-004**: 열 수 없는 파일은 "미리보기를 볼 수 없습니다"(영어 창: "No preview available")를 보여야 MUST 한다.
- **FR-005**: 앨범에 넣을 수 있는 모든 사진 형식(HEIC 포함)의 미리보기를 보여야 MUST 한다.
- **FR-006**: 사진 파일을 바꾸거나 새 파일을 만들어서는 MUST NOT 한다.
- **FR-007**: 창의 다른 동작(정렬, 옮기기, 이름 바꾸기, 앨범 만들기)과 명령줄은 바뀌지 않아야 MUST 한다.

### Key Entities

- **미리보기**: 사진 하나의 작은 그림. 파일 이름으로 찾아 같은 폴더를 보는 동안 다시 쓴다.

## Success Criteria *(mandatory)*

- **SC-001**: 일반 휴대폰 사진(약 4000×3000 JPEG)에 마우스를 올리면 1초 안에 미리보기가 뜬다. 같은 사진을 다시 볼 때는 바로 뜬다.
- **SC-002**: 마우스를 치우면 미리보기는 남아 있지 않는다(화면에 떠 있는 미리보기는 늘 0개 또는 1개).
- **SC-003**: 미리보기를 본 뒤에도 폴더의 모든 사진 파일이 바이트 단위로 그대로다.

## Assumptions

- 미리보기는 마우스를 올렸을 때만 만든다. 폴더를 열 때 모든 사진의 미리보기를 미리 만들지 않는다(큰 폴더에서 목록이 늦게 뜨지 않게).
- 미리보기는 창을 닫으면 버린다(디스크에 저장하지 않는다).
- 미리보기 크기 조절, 클릭해서 크게 보기, 목록 안에 항상 보이는 작은 그림은 범위 밖이다.
- 날짜 칸과 버튼 위에서는 미리보기를 띄우지 않는다. 파일 이름 위에서만 뜬다.
