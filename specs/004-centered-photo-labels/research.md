# Research: 글자에 꼭 맞는 메모 라벨과 페이지 정중앙에 놓이는 사진

## R1. 사진을 좌우 가운데에 두면서 라벨을 인쇄 가능 영역 안에 두는 방법

- **Decision**: 사진 자리(box)를 인쇄 가능 영역(x 10~200mm)에서 좌우 `LABEL_OUT_X`(10mm)씩 줄인 x 20~190mm(폭 170mm)로 한다. 사진은 그 안 가운데라 중심이 항상 종이 가운데(105mm)다.
- **Rationale**: 오른쪽만 비우면(지금) 사진 중심이 왼쪽으로 5mm 쏠린다. 라벨은 사진 오른쪽 변에서 최대 10mm 나오므로, 사진이 가운데이면서 라벨이 200mm를 넘지 않으려면 사진 폭이 170mm 이하여야 한다.
- **Alternatives considered**:
  - 사진 폭 180mm를 유지해 가운데(15~195mm)에 두고 라벨을 205mm까지 내밀기: 오른쪽 여백 5mm로 001 FR-007(각 변 10mm)과 가정용 프린터 인쇄 불가 영역에 걸림. 버림.
  - 사진이 넓을 때만 라벨을 덜 내밀기: 사진마다 라벨 위치가 달라져 규칙이 복잡해짐. 버림.
- **영향**: 칸 너비를 다 쓰던 넓은 사진(16:9, 파노라마)은 180→170mm로 약 5.6% 좁아진다. 높이가 먼저 꽉 차는 4:3 가로 사진(171.3mm)은 170mm로 거의 그대로이고, 세로 사진은 그대로다.

## R2. 위아래 방향

- **Decision**: 위 칸은 위쪽(페이지 가장자리 쪽)에서, 아래 칸은 아래쪽에서 `LABEL_OUT_Y`(5mm)를 줄인다. 위 box y 153.5~282, 아래 box y 15~143.5로 페이지 가운데 선(148.5mm)에 대해 대칭이다.
- **Rationale**: 지금은 두 칸 모두 위쪽 5mm를 비워, 같은 사진 두 장이면 위 사진은 가운데 선에서 69.25mm, 아래 사진은 74.25mm 떨어져 위아래로도 어긋난다. 아래 사진의 라벨은 칸 사이 간격(10mm) 안으로 5mm 나오므로 위 사진과 5mm 떨어져 겹치지 않는다. box 높이는 128.5mm로 이전과 같아 사진 크기도 같다.
- **Alternatives considered**: 위아래 모두 5mm씩 줄이기(완전 대칭 칸): 사진이 5mm 작아짐. 버림.

## R3. 라벨 최소 너비

- **Decision**: `LABEL_MIN_W` = 10mm. 한 줄 라벨 높이(11pt 기준 10.04mm)와 거의 같아, 한 글자 설명도 세로로 긴 띠가 되지 않는다.
- **Rationale**: 맑은 고딕 11pt로 잰 예시 설명 폭: "Beach" 10.4mm, "Sunset" 11.7, "Night sky" 16.8, "Mountains" 18.6, "Forest path" 20.0, "바다" 7.8, "집" 3.9. 지금(최소 30mm)은 "Beach" 라벨 오른쪽에 약 15mm가 비지만, 새 규칙으로는 15.4mm 라벨에 양옆 2.5mm씩이다.
- **Alternatives considered**: 최소 20mm(= 나오는 폭의 두 배): 짧은 설명 양옆에 여전히 5mm 안팎이 남아 "충분히 줄어든다"에 못 미침. 버림.

## R4. 작은 라벨이 사진에서 떨어져 보이지 않게

- **Decision**: 사진 밖으로 나오는 폭 = `min(LABEL_OUT_X, 라벨 너비 / 2)`.
- **Rationale**: 10mm 내밀기를 고정하면 10~15mm 라벨은 대부분이 사진 밖에 떠 "모서리에 걸친 라벨"(001 FR-005)로 보이지 않는다. 너비 20mm 이상인 라벨은 이전과 같은 10mm다.
- **Alternatives considered**: 최소 너비를 키워 해결(R3에서 버림), 내미는 폭을 모두 줄이기(기존 앨범 모양이 바뀜, 버림).

## R5. 글자 가운데 정렬

- **Decision**: 줄마다 x = 라벨 왼쪽 + (라벨 너비 − 줄 폭) / 2. 줄 폭은 이모지 대체 글꼴을 포함해 `Fonts.measure`로 잰다(그리는 폭과 같은 계산).
- **Rationale**: 라벨 너비가 가장 긴 줄 + 안쪽 여백이므로 가장 긴 줄은 안쪽 여백 2.5mm 자리에 오고, 짧은 줄은 가운데로 모인다. 최소 너비가 적용된 라벨도 글자가 가운데에 온다.
