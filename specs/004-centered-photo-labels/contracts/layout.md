# Contract: 페이지 배치 규칙 (004에서 바뀐 부분)

단위 mm, 원점은 종이 왼쪽 아래. A4 210 × 297, 인쇄 가능 영역 x 10~200, y 10~287.

## 사진 자리 (`slot_geometry(position)`)

| position | cell (x, y, w, h) | photo_box (x, y, w, h) — 이전 → 이후 |
|----------|-------------------|--------------------------------------|
| top | 10, 153.5, 190, 133.5 | 10, 153.5, 180, 128.5 → **20, 153.5, 170, 128.5** |
| bottom | 10, 10, 190, 133.5 | 10, 10, 180, 128.5 → **20, 15, 170, 128.5** |

사진은 `fit_photo`로 photo_box 안 가운데에 비율 그대로 최대 크기.

## 메모 라벨 (`fit_label` / `_build_label`)

| 값 | 이전 | 이후 |
|----|------|------|
| 최소 너비 `LABEL_MIN_W` | 30 | **10** |
| 최대 너비 `LABEL_MAX_W` | 64 | 64 |
| 너비 | clamp(가장 긴 줄 + 5) | 같음 |
| 사진 오른쪽 변 밖으로 나오는 폭 | 10 | **min(10, 너비 / 2)** |
| 사진 위쪽 변 밖으로 나오는 폭 | 5 | 5 |
| 글자 가로 위치 | 왼쪽 + 2.5 | **(너비 − 줄 폭) / 2** |

글자 크기(11→8pt), 최대 3줄, 줄바꿈, "…", 15% 가림 상한, 색·테두리·그림자는 그대로.

## 사용하는 쪽

`build_album` → `layout_pages` → 위 함수들. CLI(`make_album.py`), `/album`, 앨범 창 두 exe가 모두 이 경로라 결과가 같다. 함수 이름·인자·반환 형식은 바뀌지 않는다.
